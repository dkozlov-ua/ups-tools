UPS Tools now watches several UPSes at once, can update itself, and reconnects reliably after the PC sleeps.

- **Several UPSes**: pair as many as you like with Configuration → **Add UPS…**. They are monitored at the same time,
  each with its own scripts, *Grid lost* delay, *Battery low* limits and notification switches, and optionally a name
  of its own (e.g. *Desk*, *Server rack*).
  - With more than one, a picker next to the tabs chooses the UPS the window shows, and the dashboard has a tile for
    each with its state at a glance.
  - The tray icon takes the colour of the UPS that needs attention most; its tooltip has a line for each.
  - Notifications and the log name the UPS, and one UPS's *Grid restored* no longer replaces another's *Grid lost*.
  - Scripts get the new `UPS_NAME` variable, so one script can serve several UPSes.
- **Update button**: Configuration → About → **Check for updates**, then **Update to X.Y.Z** downloads the setup from
  this project's GitHub releases, checks it against the SHA-256 GitHub lists for it, and runs it; the app restarts with
  its window open. This release has to be installed by hand once; from then on the button does it.
- **After sleep**: UPS Tools disconnects from the UPS before the PC goes to sleep and waits 15 s after it wakes up
  before reconnecting. Reconnecting at once could catch the Bluetooth adapter mid-restart and leave an Elite 100 V2
  refusing connections for ten minutes or more.

Your existing UPS, its scripts and settings carry over: they become the first UPS in the list. The old settings file
is kept as `settings.json.before-0.7.0`; earlier versions can't read the new one.
