UPS Tools now supports EcoFlow power stations, starting with the River 3 Plus.

- **EcoFlow River 3 Plus** over Bluetooth LE: battery, grid, input and output power, and time left, updated about once
  a second. Tested on a real River 3 Plus, including pulling its plug.
- An EcoFlow device only talks to the EcoFlow account it was added to in the EcoFlow app. **Find UPS** asks for that
  account's user ID, or looks it up when you sign in with the account's email and password. Only the user ID is saved;
  the password goes to EcoFlow and nowhere else.
- A **Smart Extra Battery** plugged into the River 3 Plus counts towards the time left (286 Wh each).
- River 3, River 3 UPS and River 3 Plus Wireless use the same messages and should work too, but are untested.
- The dashboard, notifications and Configuration name the brand: "Bluetti EL100V2", "EcoFlow River 3 Plus".

Existing settings and scripts carry over as they are. To switch to an EcoFlow UPS, pair it with Configuration →
**Find UPS…**; UPS Tools watches one UPS at a time.
