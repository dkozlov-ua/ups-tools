UPS Tools now runs on Android phones and tablets too: it watches the same UPSes, notifies you of the same events,
and shares them with your PCs. Nothing changes on Windows.

- **Android app** (Android 8.0 or later): `UpsTools-0.10.0-android.apk`, attached to this release. Open it on the
  phone to install it (Android asks once to allow installing apps from that source). It has the dashboard, a
  notification for each event with the same texts, limits and per-event switches as on Windows, and **Add UPS**
  with the EcoFlow user ID or sign-in. It has no scripts.
  - **Monitoring in the background**, with a notification that stays meanwhile: a line for each UPS, and the app
    icon coloured as the tray icon (green on the grid, yellow on battery, red for battery low or unreachable). It
    starts again after the phone restarts.
  - **Network sharing with your PCs**: the same sharing code and the same Wi-Fi network. The phone can be the one
    connected to a UPS, serving your PCs, or read it through a PC, and either takes over when the other goes away.
  - **Updates**: Settings → *Check for updates* installs the next release's APK, checked against the SHA-256 GitHub
    lists for it, with the settings kept.
  - **Share log** in Settings sends the log through Android's share sheet.
  - Tested with an EcoFlow River 3 Plus on a Samsung Galaxy S22 (Android 16): monitoring, sharing with a PC,
    notifications and a real power cut.
- **On Windows**, nothing changes for you or your scripts: the Bluetooth code moved behind an interface the phone
  shares, and the network sharing messages are written exactly as before (PCs on 0.9.0 and 0.10.0 understand each
  other, and the phone).
