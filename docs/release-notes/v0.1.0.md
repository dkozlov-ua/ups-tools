First release: UPS Tools watches a Bluetti power station over Bluetooth and runs your scripts
when its state changes.

- **Dashboard**: grid status, battery level, charge/discharge rate, estimated time on battery,
  input and output power, recent activity.
- **Scripts**: attach scripts to *Grid lost*, *Grid restored*, *UPS unreachable* and
  *UPS reachable again*.
- **Configuration**: pair the UPS, close to tray, start with Windows, UPS update period.

Tested with a Bluetti Elite 100 V2. Needs the .NET 10 Desktop Runtime (x64).

This release predates `install.ps1`: it carries the bare exe and a zip of it.
