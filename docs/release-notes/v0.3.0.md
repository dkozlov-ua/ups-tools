More control over how your scripts run, a tray icon that shows the power state at a glance,
and a real installer.

**Scripts**

- **Wait until it finishes**: tick it on a script and the next one starts only after this
  one exits with code 0. If it fails (another exit code, or it can't be started), the
  scripts after it are skipped, and a notification says so.
- **Run as administrator**: the script runs elevated without a UAC prompt when the event
  fires, so it works with nobody at the PC. Ticking it asks for administrator rights once,
  to create a scheduled task (`\UpsTools` in Task Scheduler) that runs the script.
  Anything running under your account can edit such a script and have it run elevated:
  see the README.
- **Reorder** scripts by dragging them by their handle, with Alt+Up / Alt+Down, or from
  the right-click menu.
- **Changed behaviour:** when the grid comes back or the UPS answers again, the other
  event's scripts that haven't started yet are skipped. With *Grid lost* → `wait 5 minutes`
  (waited for) → `hibernate`, a 2-minute outage no longer hibernates the PC. Without any
  script set to wait, nothing changes: all scripts start at once, as before.

**Tray icon**

The whole icon is now coloured: green with the grid on, yellow on battery, red when the
UPS is unreachable, grey while connecting. It replaces the small dot in the corner.

**Installer**

UPS Tools now comes as `UpsTools-0.3.0-setup.exe`. It installs per user, without
administrator rights, into the same folder as before (`%LOCALAPPDATA%\Programs\UpsTools`),
and updates it in place. Uninstall it from Settings → Apps → *Installed apps*. The setup
isn't signed, so SmartScreen may ask you to confirm (*More info* → *Run anyway*).

If you installed 0.2.0 with `install.ps1`, just run the setup: it exits the running app,
replaces it, and starts it again. `install.ps1`, `manifest.txt` and `VERSION` from the old
installation are left in the folder; you can delete them.
