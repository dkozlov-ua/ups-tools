- **Modern Standby**: on a laptop that goes into Modern Standby (with or without network in standby) instead of
  sleeping, UPS Tools now disconnects from the UPSes first, as it does before sleep and hibernation, so another PC
  sharing them connects at once, and it reconnects when the laptop wakes up. If Windows suspends UPS Tools without
  saying so, it notices once it runs again and reconnects from scratch.
