Several PCs can now watch the same UPS: they find each other on your network, and only one of them connects to it.

- **Network sharing**: turn on Configuration → Network sharing → **Share with other PCs** on each PC, with the same
  sharing code (the first PC makes one up: copy it, and paste it on the others).
  - The PCs find each other on their own, and only one of them connects to each UPS over Bluetooth (it accepts a
    single connection). The others read it through that PC, getting each reading as soon as it has it, and run their
    own scripts and notifications with their own limits. The dashboard and the list of UPSes say which PC a UPS is
    read through; the card lists the PCs found.
  - If the connected PC exits, sleeps, shuts down or turns sharing off, another one connects at once; if it drops off
    the network, after about 17 s. One that can't reach the UPS for 2 minutes (e.g. out of range) lets another try.
  - **Add UPS…** lists the UPSes the other PCs are connected to.
  - Only PCs with the code take part: everything they send each other is encrypted and authenticated with keys made
    from it, so nobody else on the network can read the UPS or fake a reading. Windows may ask once whether UPS Tools
    may use the network: allow it on private networks.
- **Shutting down**: UPS Tools disconnects from the UPSes when Windows shuts down, restarts or signs out, as it
  already did before sleep and hibernation.
- **Clearer names** for the event limits: *Grid lost grace period*, *Low battery threshold*, *Time on battery left
  threshold* and *UPS unreachable on battery grace period*.
- The tray tooltip has "UPS Tools" on a line of its own, above a line for each UPS.
- The UPS update period is 60 s on new installs (existing settings keep theirs).
