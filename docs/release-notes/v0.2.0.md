Power changes now show up as Windows notifications.

- **Grid lost** says the battery level and how long it lasts at the current load:
  *Battery 87 % · about 6 h 10 m left at 120 W*. It stays on screen longer than the others.
- **Grid restored** says how long the outage lasted, and replaces the *Grid lost*
  notification, so Notification Center shows the current state.
- **UPS unreachable** says when the UPS last answered; **UPS reachable again** replaces it.
- Each notification names the scripts it started, and any that could not be started.
- Clicking a notification opens UPS Tools.
- **Configuration → Notifications** turns them on or off per event (all on by default),
  sends a test notification, and opens the Windows notification settings.

The events themselves, and when your scripts run, are unchanged. Notifications follow
Windows' own settings: Do not disturb hides them.

This is the first release that ships `install.ps1`. To install, unzip and run
`powershell -ExecutionPolicy Bypass -File install.ps1 -Launch`.
